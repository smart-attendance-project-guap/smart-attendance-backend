## Итог и ограничения
1. **Структурно объединения корректны относительно исходного JSON:** 22 объекта и 176 развернутых строк совпадают с исходником.
2. **Состав групп и недельные шаблоны согласуются с доступными записями на официальном сайте**, включая новую субботнюю пару Куртяника. Но доступные индексированные страницы относятся к разным сборкам расписания; это **не доказательство точности каждой даты 24.11–19.12**.
3. Для окончательного подтверждения перед реальным использованием надо открыть [актуальное расписание ГУАП](https://guap.ru/rasp) (на момент сверки указана сборка 17.11.2026) и проверить исключения по датам, чередование недель, изменения аудиторий и ФИО преподавателей физкультуры.
4. **Не меняем исходные `data/*.json` без подтверждения.** Для интеграционного теста используем тестовую БД и тестовые TEACHER-аккаунты. Ни в `JSON`, ни в GitHub не записывать реальные пароли.
5. Даша и Женя могут подключать UI к существующему API, но импорт в общую/боевую БД и слияние PR — только после сверки календаря и совместного тестирования.
